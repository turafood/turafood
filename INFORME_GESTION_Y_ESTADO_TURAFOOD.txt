1. RESUMEN EJECUTIVO DE LAS 3 APLICACIONES (PORTALES) Y BASE DE DATOS
--------------------------------------------------------------------------------

El ecosistema TuraFood opera bajo una arquitectura de 3 portales interconectados 
en tiempo real con Supabase (PostgreSQL + Realtime WebSockets):

  1. turafood.com (turafood-cliente) -> App Web & PWA para Clientes Finales
     - Puerto Local: http://localhost:4005
     - Estado de Build: 22/22 Rutas OK (0 Errores)
     - Audiencia: Consumidores de Buenaventura que piden comida, licores y mercado.

  2. app.turafood.com (turafood-app) -> Portal para Restaurantes y Repartidores
     - Puerto Local: http://localhost:3000
     - Estado de Build: 54/54 Rutas OK (0 Errores)
     - Audiencia: Dueños de restaurantes (gestión de menú, kanban de pedidos) y repartidores.

  3. dash.turafood.com (turafood-admin) -> SuperAdmin y Consola Global de Operaciones
     - Puerto Local: http://localhost:3001
     - Estado de Build: 16/16 Rutas OK (0 Errores)
     - Audiencia: Equipo directivo de TuraFood (comisiones, auditoría, aprobaciones y finanzas).

  4. Supabase DB (turafood-supabase) -> Base de datos unificada en tiempo real
     - Tablas clave: profiles, business_profiles, courier_profiles, orders, 
                     order_items, messages, reviews, zones, coupons.
     - Realtime: Habilitado en orders, messages y reviews.

3. MATRIZ DE SINCRONIZACIÓN ENTRE PORTALES
--------------------------------------------------------------------------------

Flujo Transaccional Integrado:

   [CLIENTE (turafood.com)]
             │
             │  1. Cliente confirma pedido (2 clics)
             ▼
     [SUPABASE DATABASE]  ◄─────── Realtime Pub/Sub (WebSockets)
             │
             ├─────────────────────────────────────────────────┐
             │ 2. Evento instantáneo                            │ 3. Notificación Admin
             ▼                                                 ▼
   [NEGOCIO (app.turafood.com)]                       [ADMIN (dash.turafood.com)]
   - Suena timbre en cocina                            - Incrementa GMV en vivo
   - Cambia a "En Preparación"                         - Monitorea tiempos de entrega
             │
             │ 4. Asigna / Toma Repartidor
             ▼
   [REPARTIDOR (app.turafood.com/repartidor)]
   - Inicia ruta con GPS
             │
             │ 5. Evento de GPS y Estado en Vivo
             ▼
    [CLIENTE (turafood.com/tracking)]
    - La moto avanza en el mapa de Buenaventura
    - Notificación Push en pantalla del celular/PC
              │
              │ 6. En caso de incidencia (plato faltante, demora, derrame)
              ▼
    [SUITE DE GARANTÍA & DEVOLUCIONES (turafood.com/help)]
    - Autogestión tipo Rappi / Uber en 4 clics.
    - Abono instantáneo en TuraCréditos (+10% Bonus) directo a Billetera.
    - Opción de reembolso directo a Nequi / Daviplata o Reenvío Express.
    - Generación de comprobante digital y número de radicado.
